# Требования: вкладка «🗂️ Учить» (карточки в стиле Tinder)

Дополнение к приложению `deutsch_verben_1-270.html` (см. `trenazher-glagoly-1-35.md`). Добавляется третья вкладка рядом с существующими **🎯 Тренажёр** и **📖 Словарь** — обе остаются без изменений.

---

## 1. Статусы глагола (обновлённая модель — 4 статуса)

Статус теперь общий для Тренажёра, Словаря и Учить, хранится в едином прогресс-сторе на все 270 глаголов.

| Статус | Обозначение | Как присваивается |
|---|---|---|
| Новое | 📘 | по умолчанию, ничего не происходило |
| Невыученное | 📕 | свайп влево в Учить (только если было 📘) ИЛИ ошибка в Тренажёре |
| Повторено | 🟡 | свайп вправо в Учить (только если было 📘) |
| Выучено | 📗 | **только** правильный ответ в Тренажёре (текстовый ввод перевода + Perfekt) |

**Важно:** 🟡 «Повторено» — это самооценка пользователя («вроде помню»), не подтверждённое знание. Такие карточки **обязательно остаются в пуле Тренажёра** наравне с 📘 и 📕, пока не будут подтверждены текстовым вводом.

Ручное перемещение глагола между любыми из 4 статусов остаётся доступно в Словаре (как и раньше).

### Влияние на Тренажёр
Режимы фильтрации при выборе теста: весь диапазон / новые+невыученные+повторённые / только невыученные / только повторённые / только выученные. 🟡 по умолчанию входит в общий пул «ещё не подтверждено».

### Экспорт/импорт JSON
Добавляется 4-е значение статуса. Обратная совместимость: старые файлы экспорта без 🟡 читаются нормально, отсутствующий статус трактуется как есть (📘/📕/📗ит.д. без потери данных).

---

## 2. Экран настройки просмотра (перед стартом и по кнопке «Выбрать другой набор»)

- **Диапазон глаголов**: от–до (числами) или пресеты по 35 (1–35 … «Все 1–270»)
- **Фильтр по статусу — чекбоксы, можно выбрать несколько**: 📘 Новые / 📕 Невыученные / 🟡 Повторено / 📗 Выучено. По умолчанию все включены.
- Настройки (диапазон + фильтр) запоминаются между заходами в рамках сессии

---

## 3. Колода карточек

- Без счётчика «осталось N» — свободное листание
- Когда набор карточек заканчивается, колода **зацикливается** (начинается заново по тому же набору), пустой экран не показывается
- Кнопка **«Завершить / выбрать другой набор»** видна постоянно (например, в шапке) → возврат на экран настройки (п. 2) с сохранёнными предыдущими значениями, которые можно тут же поменять

---

## 4. Карточка — 3 состояния по тапу (циклически, далее снова к состоянию 1)

**Состояние 1 — основной вид** (показывается при открытии карточки и после каждого свайпа)
- Фон: сильно заблюренная (CSS `filter: blur(...)`) иллюстрация глагола
- Текст: инфинитив + **Präsens · Präteritum** + **Perfekt** (те же формы и оформление, что в Словаре, включая цвет по `hat`/`ist`)
- Бейдж статуса в углу: 📘 / 📕 / 🟡 / 📗

**Тап 1** → формы глагола скрываются, вместо них показывается **перевод на русский**. Фон остаётся заблюренным, бейдж статуса виден.

**Тап 2** → иллюстрация полностью расфокусируется (блюр снимается) — чистая картинка. Весь текст, иконки и бейдж скрываются, **кроме** примера предложения (см. ниже).
- Внизу карточки — **пример предложения** с этим глаголом (на немецком), поверх чистой иллюстрации. Оформление ненавязчивое (подложка/градиент под текстом для читаемости на фото), без перевода примера.

**Тап 3** → возврат к состоянию 1.

---

## 5. Свайпы

Свайп **влияет только на карточки со статусом 📘 «Новое»**. Для карточек в статусах 📕/🟡/📗 свайп в любую сторону — это просто переход к следующей карточке, статус не меняется (защита от случайного сбоя уже выставленных статусов).

| Текущий статус | Свайп вправо («помню») | Свайп влево («не помню») |
|---|---|---|
| 📘 Новое | → 🟡 Повторено | → 📕 Невыученное |
| 📕 / 🟡 / 📗 | без изменений, листает дальше | без изменений, листает дальше |

**Единственный путь к статусу 📗 «Выучено» — Тренажёр** (правильный текстовый ответ: перевод + Perfekt со вспомогательным глаголом). Ошибка в Тренажёре переводит слово в 📕.

---

## 6. Примеры предложений

- На каждый из 270 глаголов нужен **один пример предложения** на немецком, использующий именно этот глагол (желательно в Perfekt или Präteritum — форме, которую тренируют).
- Источник: сгенерировать заранее (или подобрать вручную по аналогии с примерами в `modus-und-zeiten-obzor.md` / `praepositionen-und-kasus.md`) и зашить в тот же массив данных глаголов, что и перевод/формы — отдельным полем, например `example`.
- Показывается **только** в состоянии 3 карточки (чистая иллюстрация без блюра), внизу поверх картинки.
- Перевод примера не показывается (лаконичность), при необходимости пользователь сверяется по контексту/словарю.

---

## 7. Иллюстрации

Подбираются вручную пользователем по каждому глаголу (не автогенерация).

**Формат и параметры:**
- **WebP**, качество ~75–80%
- Размер исходника: **~800×1200 px** (2x под retina-плотность карточки)
- Целевой вес файла: **30–80 КБ** на изображение → суммарно на 270 карточек ориентировочно 10–20 МБ
- Файлы хранятся **отдельно от HTML** (не base64), название по номеру глагола: `verb-images/001.webp`, `002.webp` … `270.webp` — совпадает с номером `№` из таблицы `Unregelmaessige_Verben.pdf`
- Блюр (состояние 1–2) реализуется CSS-фильтром поверх обычного изображения — отдельная «размытая» версия файла не нужна
- **Lazy loading** — изображения подгружаются по мере пролистывания карточек, не все 270 сразу

---

## 8. Что не входит в эту итерацию (сознательно отложено)

- Автогенерация иллюстраций — пользователь подбирает вручную
- Прогресс-бар / счётчик карточек в колоде — не нужен
- Spaced repetition / повторные подтверждения для перехода в 🟡→📗 — переход только через Тренажёр, без промежуточных ступеней
