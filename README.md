# DieFliegendeKuh — тренажёр немецких глаголов

Два курса на выбор: все **270 базовых неправильных глаголов** (формы) и **111 глаголов с предлогами** (Verben mit Präpositionen). Работает офлайн в любом браузере — установка, сервер и интернет не нужны.

## Онлайн-версия
Открыть без скачивания: **https://aamirlatif1.github.io/DieFliegendeKuhApp/**

Прогресс сохраняется в браузере так же, как и в офлайн-версии, и переносится между ними через экспорт/импорт JSON.

## Быстрый старт (офлайн)
1. Скачайте репозиторий целиком (кнопка **Code → Download ZIP**) и распакуйте его.
2. Откройте `index.html` двойным кликом — он запустится в браузере по умолчанию.

> Важно: `index.html` нужно держать рядом с папками `css/`, `js/`, `data/` и `verb-images/` — без них приложение не запустится. Скачивать один только HTML-файл больше не достаточно.

Пошаговая инструкция — в [HOWTOUSE.md](HOWTOUSE.md).

## Что внутри
Вверху — переключатель языка интерфейса **RUS/ENG/ITA**, переключатель курса и три вкладки.

Курс выбирается кнопками **🔤 Формы глаголов** / **🔗 Глаголы с предлогами**; у каждого курса свои диапазоны и свой прогресс. Все три вкладки работают в обоих курсах:

- **🎯 Тренажёр** — по выбранному диапазону вводите перевод и вторую форму: **Perfekt** (`hat abgebrochen`) в курсе форм или **предлог + падеж** (`über + A`) в курсе предлогов, где вопрос сопровождается примером с пропуском. В конце — разбор ошибок.
- **📖 Словарь** — таблица всего курса: формы или предлог с падежом, перевод, поиск, фильтры, режим самопроверки (скрыть перевод / вторую колонку).
- **🗂️ Карточки** — листалка в стиле Tinder: формы (или пример с пропуском) → перевод (и предлог) → пример предложения целиком; свайп вправо/влево (или ←/→).

Прогресс единый для всех вкладок — 4 статуса (📘 Новое / 🟡 Повторено / 📕 Невыученное / 📗 Выучено), хранится отдельно для каждого курса, сохраняется в браузере автоматически, плюс экспорт/импорт в JSON (в файл попадают оба курса сразу).

## Иллюстрации для «Карточки»
Лежат в `verb-images/NNN-infinitiv.webp` — сейчас заполнено 31 из 270, для остальных показывается нейтральная заглушка. В курсе предлогов картинок нет — карточка всегда показывает заглушку. Формат и правила добавления новых картинок — в [verb-images/README.md](verb-images/README.md).
