# DieFliegendeKuh — тренажёр немецких неправильных глаголов

Один HTML-файл (`DieFliegendeKuhApp.html`), тренирует все **270 базовых неправильных глаголов** немецкого. Работает офлайн в любом браузере — установка, сервер и интернет не нужны.

## Быстрый старт
1. Скачайте `DieFliegendeKuhApp.html` из репозитория.
2. Откройте файл двойным кликом — он запустится в браузере по умолчанию.

Пошаговая инструкция — в [HOWTOUSE.md](HOWTOUSE.md).

## Что внутри
Вверху — переключатель языка интерфейса **RUS/ENG/ITA** и три вкладки:

- **🎯 Тренажёр** — по выбранному диапазону глаголов вводите перевод и форму **Perfekt** (`hat abgebrochen`), в конце — разбор ошибок.
- **📖 Словарь** — таблица всех 270 глаголов: формы, перевод, поиск, фильтры, режим самопроверки (скрыть перевод/Perfekt).
- **🗂️ Учить** — карточки в стиле Tinder: инфинитив + формы → перевод → чистая иллюстрация с примером предложения; свайп вправо/влево (или ←/→).

Прогресс единый для всех вкладок — 4 статуса (📘 Новое / 🟡 Повторено / 📕 Невыученное / 📗 Выучено), сохраняется в браузере автоматически, плюс экспорт/импорт в JSON.

## Иллюстрации для «Учить»
Лежат в `verb-images/NNN-infinitiv.webp` — сейчас заполнено 31 из 270, для остальных показывается нейтральная заглушка. Формат и правила добавления новых картинок — в [verb-images/README.md](verb-images/README.md).
