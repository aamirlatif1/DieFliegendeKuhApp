# Как установить и начать пользоваться DieFliegendeKuh

Приложение — это один HTML-файл `DieFliegendeKuhApp.html`. Ему не нужен сервер, установка или интернет: он работает прямо в браузере.

## 1. Скачать файл

Выберите один из вариантов.

**Вариант А — без Git (проще всего):**
1. Откройте страницу репозитория: https://github.com/kiselkath/DieFliegendeKuhApp
2. Нажмите на файл `DieFliegendeKuhApp.html`.
3. Нажмите кнопку **Download raw file** (или значок скачивания).
4. Сохраните файл на компьютер (например, на Рабочий стол).

**Вариант Б — через Git:**
```
git clone https://github.com/kiselkath/DieFliegendeKuhApp.git
```
Файл `DieFliegendeKuhApp.html` появится в скачанной папке.

## 2. Открыть приложение

Дважды кликните по файлу `DieFliegendeKuhApp.html` — он откроется в браузере по умолчанию (Chrome, Firefox, Edge, Safari — подойдёт любой современный браузер).

Если файл не открылся сам: откройте браузер и перетащите файл в окно браузера, либо `Файл → Открыть файл...`.

## 3. Выбор языка

Вверху страницы есть переключатель **RUS/ENG** — он меняет и язык интерфейса, и язык, на котором нужно вводить перевод в тренажёре и который показывается в словаре. Выбор запоминается в браузере.

## 4. Вкладка «Тренажёр»

1. Вверху страницы выберите вкладку **🎯 Тренажёр**.
2. Задайте диапазон глаголов — вручную («от … до») или пресетом по 35 (1–35, 36–70 и т.д., либо «Все 1–270»). Кнопка «Начать» станет активной только после того, как диапазон выбран корректно.
3. Выберите режим: весь диапазон / новые + невыученные / только невыученные / только выученные.
4. Нажмите **Начать**.
5. Для каждого глагола (инфинитив, например `abbrechen`) введите:
   - перевод (на русский или английский, в зависимости от выбранного языка);
   - форму **Perfekt** со вспомогательным глаголом (например, `hat abgebrochen`).
6. Перевод проверяется мягко (по корню слова), Perfekt — строго, но с учётом допустимых вариантов (`hat`/`ist`, `angewendet`/`angewandt` и т.п.) и умлаутов как `ae`/`oe`/`ue`/`ss`.
7. Если считаете свой ответ верным, а система не засчитала — используйте кнопку «засчитать/ошибка», чтобы скорректировать оценку вручную.
8. В конце теста откроется **разбор ошибок**: таблица «ваш ответ vs правильный ответ».
9. Глаголы автоматически распределяются по папкам: 📗 Выучено / 📕 Невыучено / 📘 Новые.

## 5. Вкладка «Словарь»

1. Переключитесь на вкладку **📖 Словарь**, чтобы полистать все 270 глаголов перед тестом.
2. Для каждого глагола видно: №, инфинитив (+ подсказка для омонимов), Präsens · Präteritum, Perfekt (цвет показывает `hat`/`ist`), перевод и папку-статус.
3. Ищите глагол по номеру, инфинитиву, переводу или Perfekt через строку поиска.
4. Фильтруйте список: Все / В диапазоне / 📗 / 📕 / 📘.
5. Прямо в таблице можно переместить глагол между папками.
6. Для самопроверки включите «Скрыть перевод» и/или «Скрыть Perfekt» — ячейки размоются, клик по ячейке покажет ответ.

## 6. Сохранение и перенос прогресса

- Прогресс сохраняется **автоматически в браузере** (localStorage) — при повторном открытии файла в том же браузере на этом же устройстве всё восстановится.
- Если очистите данные браузера или откроете файл в другом браузере/на другом устройстве, прогресс не подтянется автоматически — используйте экспорт/импорт:
  - **Экспорт**: кнопка экспорта сохранит JSON-файл с именем вида `verben_progress_ГГГГ-ММ-ДД_ЧЧ-ММ-СС.json`.
  - **Импорт**: на новом устройстве/в другом браузере откройте приложение и импортируйте этот JSON-файл — прогресс восстановится.

## Требования

- Любой современный браузер (Chrome, Firefox, Edge, Safari).
- Интернет и сервер не нужны — файл работает локально, офлайн.
