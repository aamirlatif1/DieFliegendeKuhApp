# Как установить и начать пользоваться DieFliegendeKuh

Приложение открывается файлом `index.html`, рядом с которым лежат папки `css/`, `js/`, `data/` и `verb-images/`. Ему не нужен сервер, установка или интернет: оно работает прямо в браузере.

## 1. Скачать приложение

**Вариант 0 — вообще не скачивать:** приложение опубликовано онлайн по адресу https://aamirlatif1.github.io/DieFliegendeKuhApp/ — откройте ссылку, и шаги 1 и 2 можно пропустить. Скачивание нужно, только если вы хотите пользоваться приложением совсем без интернета.

Скачивать нужно **всю папку целиком**, а не один HTML-файл: без папок `css/`, `js/` и `data/` приложение не запустится. Выберите один из вариантов.

**Вариант А — без Git (проще всего):**
1. Откройте страницу репозитория: https://github.com/kiselkath/DieFliegendeKuhApp
2. Нажмите зелёную кнопку **Code** и выберите **Download ZIP**.
3. Сохраните архив на компьютер и распакуйте его (например, на Рабочий стол).

**Вариант Б — через Git:**
```
git clone https://github.com/kiselkath/DieFliegendeKuhApp.git
```
Папка с приложением появится на компьютере.

## 2. Открыть приложение

Дважды кликните по файлу `index.html` внутри распакованной папки — он откроется в браузере по умолчанию (Chrome, Firefox, Edge, Safari — подойдёт любой современный браузер).

Если файл не открылся сам: откройте браузер и перетащите файл в окно браузера, либо `Файл → Открыть файл...`.

Не перемещайте `index.html` отдельно от соседних папок `css/`, `js/`, `data/` и `verb-images/` — переносите всю папку целиком. Если открыть один HTML-файл без них, страница загрузится пустой.

## 3. Выбор языка

Вверху страницы есть переключатель **RUS/ENG/ITA** — он меняет и язык интерфейса, и язык, на котором нужно вводить перевод в тренажёре и который показывается в словаре. Выбор запоминается в браузере.

## 4. Выбор курса

Под шапкой находится переключатель курса:

- **🔤 Формы глаголов** — 270 неправильных глаголов: Präsens, Präteritum, Perfekt.
- **🔗 Глаголы с предлогами** — 111 устойчивых связок «глагол + предлог» с падежом (`sich ärgern über + A`).

Курс запоминается в браузере. У каждого курса **свой диапазон и свой прогресс**: папки, счётчики и статусы одного курса никак не влияют на другой. Переключать курс можно на вкладках «Тренажёр», «Словарь» и на экране настройки карточек; во время теста переключатель скрыт.

## 5. Вкладка «Тренажёр»

1. Вверху страницы выберите вкладку **🎯 Тренажёр**.
2. Задайте диапазон глаголов — вручную («от … до») или пресетом (по 35 в курсе форм: 1–35, 36–70 …; по 25 в курсе предлогов: 1–25, 26–50 …; либо «Все»). Кнопка «Начать» станет активной только после того, как диапазон выбран корректно.
3. Выберите режим: весь диапазон / новые + невыученные + повторённые / только невыученные / только повторённые / только выученные.
4. Нажмите **Начать**.
5. Для каждого глагола введите:
   - перевод (на русский, английский или итальянский — в зависимости от выбранного языка);
   - в курсе форм — **Perfekt** со вспомогательным глаголом (например, `hat abgebrochen`);
   - в курсе предлогов — **предлог** (например, `über`) и падеж кнопкой **Akkusativ (A)** / **Dativ (D)**. Падеж можно вместо этого дописать в поле: `über + A`, `ueber akkusativ`. Под глаголом показывается пример с пропуском (`Wir ärgern uns ___ den Regen.`) — он подсказывает контекст и различает глаголы с несколькими предлогами (`bestehen aus` / `bestehen auf`).
6. Перевод проверяется мягко (по корню слова), Perfekt — строго, но с учётом допустимых вариантов (`hat`/`ist`, `angewendet`/`angewandt` и т.п.) и умлаутов как `ae`/`oe`/`ue`/`ss`. Предлог засчитывается только вместе с правильным падежом; умлауты тоже можно писать как `ue`.
7. Если считаете свой ответ верным, а система не засчитала — используйте кнопку «засчитать/ошибка», чтобы скорректировать оценку перевода вручную.
8. В конце теста откроется **разбор ошибок**: таблица «ваш ответ vs правильный ответ».
9. Глаголы автоматически распределяются по папкам: 📗 Выучено / 📕 Невыучено / 📘 Новые (🟡 «Повторено», если ошиблись/угадали, остаётся в общем пуле до подтверждения).

## 6. Вкладка «Словарь»

1. Переключитесь на вкладку **📖 Словарь**, чтобы полистать весь курс перед тестом.
2. В курсе форм для каждого глагола видно: №, инфинитив (+ подсказка для омонимов), Präsens · Präteritum, Perfekt (цвет показывает `hat`/`ist`), перевод и папку-статус.
3. В курсе предлогов вместо форм показан пример предложения, а вместо Perfekt — предлог с падежом (цвет показывает Akkusativ/Dativ).
4. Ищите глагол по номеру, инфинитиву, переводу, Perfekt или предлогу через строку поиска.
5. Фильтруйте список: Все / В диапазоне / 📗 / 📕 / 🟡 / 📘.
6. Прямо в таблице можно переместить глагол между папками (включая 🟡 «Повторено»).
7. Для самопроверки включите «Скрыть перевод» и/или «Скрыть Perfekt» (в курсе предлогов — «Скрыть предлог») — ячейки размоются, клик по ячейке покажет ответ.

## 7. Вкладка «Карточки» — листалка в стиле Tinder

1. Переключитесь на вкладку **🗂️ Карточки**.
2. На экране настройки задайте диапазон глаголов и отметьте, какие статусы включить в подборку (📘/📕/🟡/📗 — по умолчанию все включены). Нажмите **▶ Начать**.
3. Карточка открывается в виде 1: инфинитив + Präsens · Präteritum · Perfekt на размытой иллюстрации, в углу — бейдж текущего статуса. В курсе предлогов вместо форм показан пример с пропуском вместо предлога.
   - **Тап** по карточке → показывается перевод вместо форм (в курсе предлогов — предлог с падежом и перевод; иллюстрация остаётся размытой).
   - **Ещё тап** → иллюстрация становится чёткой, весь текст скрывается, кроме примера предложения на немецком внизу карточки (уже с предлогом).
   - **Ещё тап** → карточка возвращается к виду 1.
4. **Свайп** карточки вправо («помню») или влево («не помню») — либо стрелки ←/→ на клавиатуре:
   - для глагола со статусом 📘 «Новое» свайп вправо ставит 🟡 «Повторено», влево — 📕 «Невыученное»;
   - для глаголов, уже имеющих статус 📕/🟡/📗, свайп просто переключает на следующую карточку без изменения статуса (защита от случайной правки).
   - Единственный способ получить 📗 «Выучено» — правильный ответ в Тренажёре.
5. Колода зациклена: после последней карточки набор начинается заново. Кнопка **«🏁 Завершить / выбрать другой набор»** всегда видна вверху и возвращает на экран настройки.
6. **Иллюстрации** есть только в курсе форм; в курсе предлогов карточка всегда показывает заглушку 🐄. Файлы лежат в папке `verb-images/`, имена вида `NNN-инфинитив.webp`: `verb-images/001-abbrechen.webp`, `verb-images/002-abfahren.webp` … `verb-images/270-zwingen.webp` (номер соответствует № из таблицы). Сейчас заполнена только часть из 270 — остальные можно добавить самостоятельно (формат — WebP, ~800×1200 px, ~30–80 КБ на файл; полный список имён и правила — в `verb-images/README.md`). Пока файла для глагола нет, карточка показывает нейтральную заглушку 🐄 — остальной функционал работает как обычно.

## 8. Сохранение и перенос прогресса

- Прогресс сохраняется **автоматически в браузере** (localStorage), отдельно для каждого курса — при повторном открытии файла в том же браузере на этом же устройстве всё восстановится.
- Если очистите данные браузера или откроете файл в другом браузере/на другом устройстве, прогресс не подтянется автоматически — используйте экспорт/импорт:
  - **Экспорт**: кнопка экспорта сохранит JSON-файл с именем вида `verben_progress_ГГГГ-ММ-ДД_ЧЧ-ММ-СС.json` — в него попадает прогресс **обоих курсов** сразу.
  - **Импорт**: на новом устройстве/в другом браузере откройте приложение и импортируйте этот JSON-файл — прогресс восстановится. Старые файлы экспорта (без раздела курсов) считаются прогрессом курса форм.

## Требования

- Любой современный браузер (Chrome, Firefox, Edge, Safari).
- Интернет и сервер не нужны — приложение работает локально, офлайн.
